# Metavision Hardware Manuals

This folder stores local copies of camera hardware manuals used for the EVK4 VLC experiments.

## Manuals

- [EVK4 HD Prophesee Evaluation Kit Camera Manual](EVK4_HD_Prophesee_Evaluation_Kit_Camera_Manual.pdf)

Use this manual for camera hardware setup details, connector/pin information, and physical EVK4 reference material. For SDK behavior, CLI flags, and current API details, prefer the local Metavision notes in `../downloaded_pages/` or the live official docs.
